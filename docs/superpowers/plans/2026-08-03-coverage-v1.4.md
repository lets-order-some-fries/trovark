### Task W1 — Correctness: stop publishing "F" for repos we never fetched  ⚠️ ship first

**The bug (verified):** 18 of 400 index entries are repos that GitHub 404s (deleted/renamed). They are published with `ok:true`, `overall:0`, `grade:"F"`, all four dimensions 0. We assert a failing grade on repos that don't exist. 19% of the withheld pile.

**Fix:**
- Distinguish "repo could not be resolved" from "repo read but tools unreadable". On a GitHub 404 for the repo-metadata call, mark the entry `ok:false` with a `resolveError`, OR add `unresolved: true` — either way it must NOT carry `grade`/`overall` (null them, like `notServer` does) and must be excluded from `gradeDist`, `avgOverall`, `staleOver180`, `secretsFindings`, `shellExecTools`.
- Add `unresolved: number` to `IndexStats`; render these distinctly on the site (e.g. "repo unavailable") — never as a graded or F row.
- Follow one rename redirect before giving up: GitHub returns 301 with the new location for renames; a true 404 means gone. Re-resolve once, then mark unresolved.
- CLI: an unresolved ref should exit 2 with a clear message, not print an F card.

- [ ] RED tests: a fake Http whose repo-metadata call 404s → the card/entry is unresolved with null grade/overall; `summarize` excludes it from all five counters and reports `unresolved: 1`; a 301 rename is followed once and then scored normally.
- [ ] Implement; `npm test` + build green; commit `fix: never publish a grade for an unresolved repo (18 false F cards)`.

**(b) Dynamic tool surface** (spec §1a). Add `'dynamic'` terminal outcome for servers that build their tool list at runtime (MCPJungle: `AddTool(tool, …)` where tools come from `db.Find(&tools)`). Fire ONLY after every static extractor returns 0, and ONLY on: structural signal A (registration call with a bare-identifier first arg + a persistence/deserialize marker **in the same directory**), or (B && C) where B is the weak gateway/proxy keyword signal and C is structural corroboration (migrations dir / `models/*tool*` file). **Never B alone — measured 7/10 false positives.**
Shape it exactly like `notServer`: `overall: null`, `grade: null`, dimensions still shown, label `DYNAMIC TOOL SURFACE — not statically analyzable`, note explaining tools come from upstream at runtime. Do NOT renormalize security onto the remaining signals — a gateway with unknown tools is the highest-risk shape in the corpus, not a neutral one.
